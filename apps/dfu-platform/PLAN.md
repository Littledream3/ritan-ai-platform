# DFU 糖尿病足溃疡智能分级与建议系统 — 实现计划书

## 一、项目目标

基于 ADPM V3.3 数据集（10,062 张 DFU 图片，Grade 1–4），训练一个深度学习模型，实现：
1. **自动分级**：输入 DFU 局部伤口图片，输出 Grade 1–4 严重程度
2. **分级分析**：对分级结果进行可解释性分析（哪些特征决定了分级）
3. **患者建议**：根据分级结果生成个性化的治疗和生活建议

### 2.2 存在的问题与处理

| 问题 | 处理方案 |
|------|---------|
| 测试集太小（141 张）且 Grade 3 仅 18 张 | **重新划分数据集**：按 70/15/15 比例重新分割 |
| 原始图片仅 ~1,373 张，其余为增强副本 | 按原始图片分组后再划分，**防止数据泄漏**（同一原始图片的不同增强版本不能同时出现在训练集和测试集） |
| 类别有轻度不均衡（Grade 3 偏多） | 使用类别加权损失函数（Class-Weighted CrossEntropy） |

## 三、模型选型

### 3.1 主模型：ResNet-50（推荐首选）

| 方面 | 详情 |
|------|------|
| **选择理由** | DFU 分级文献中验证最充分的架构。Ramadhan et al. (2025) 在 Wagner 6 分类上达到 F1=0.95；ScoreDFUNet (Nature 2024) 使用 ResNet-50 达到 95.34% 准确率 |
| **预训练** | ImageNet-1K 预训练权重 |
| **修改** | 替换最后一层 FC 为 `Linear(2048, 4)` |
| **输入** | 224×224×3 |
| **参数量** | ~23.5M |

### 3.2 对比模型：EfficientNet-B3

| 方面 | 详情 |
|------|------|
| **选择理由** | 在 DFUC 挑战赛中被广泛使用，计算效率高，适合后续移动端部署 |
| **预训练** | ImageNet-1K 预训练权重 |
| **修改** | 替换分类头为 `Linear(1536, 4)` |
| **输入** | 300×300×3（EfficientNet-B3 标准输入） |

### 3.3 可选进阶模型：ConvNeXt-Tiny

| 方面 | 详情 |
|------|------|
| **选择理由** | ADPM 原项目使用的架构，现代化设计，性能优于 ResNet |
| **预训练** | ImageNet-1K 预训练权重 |
| **修改** | 替换分类头为 `Linear(768, 4)` |

### 3.4 最终策略

```
第一轮：ResNet-50（快速验证可行性）
第二轮：EfficientNet-B3（对比实验）
第三轮：选表现最好的模型做精调 + 可解释性分析
```

## 五、详细实现步骤

### 阶段 1：数据预处理（预计 1-2 天）

```
步骤 1.1：按原始图片分组
  - 利用文件名特征（.rf. 之前的部分）识别同一原始图片的增强版本
  - 同一原始图片的所有版本归为一组

步骤 1.2：重新划分数据集
  - 按组进行分层划分（Stratified Group Split）
  - 训练集 70% / 验证集 15% / 测试集 15%
  - 确保每个级别在各集合中的比例一致

步骤 1.3：数据增强（训练集）
  - RandomHorizontalFlip(p=0.5)
  - RandomRotation(±15°)
  - RandomResizedCrop(224, scale=(0.8, 1.0))
  - ColorJitter(brightness=0.2, contrast=0.2, saturation=0.1, hue=0.05)
  - RandomAffine(translate=(0.05, 0.05))
  - Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])

步骤 1.4：验证集/测试集预处理
  - Resize(224) → CenterCrop(224) → Normalize（不做增强）
```

### 阶段 2：模型训练（预计 2-3 天）

```
步骤 2.1：Baseline 训练配置
  - 优化器：     AdamW (lr=1e-4, weight_decay=1e-4)
  - 学习率策略：  CosineAnnealingWarmRestarts 或 ReduceLROnPlateau
  - 损失函数：    CrossEntropyLoss（带类别权重）
  - Batch Size：  64（根据 GPU 显存调整）
  - Epochs：      50（Early Stopping patience=10）
  - 混合精度：    Automatic Mixed Precision (AMP)

步骤 2.2：训练策略
  1. 冻结 backbone，只训练分类头 5 个 epoch（warmup）
  2. 解冻全部参数，训练 50 epoch
  3. 使用 Label Smoothing (α=0.1) 防止过拟合

步骤 2.3：评估指标
  - Accuracy（总体准确率）
  - Macro F1-Score（处理类别不均衡）
  - Per-class Precision / Recall / F1
  - Confusion Matrix（重点关注邻级混淆）
  - Cohen's Kappa（与临床评估的一致性）

步骤 2.4：模型对比
  - ResNet-50 vs EfficientNet-B3 vs ConvNeXt-Tiny
  - 记录每轮的训练/验证 loss 曲线
  - 在测试集上做最终对比
```

### 阶段 3：可解释性分析（预计 1 天）

```
步骤 3.1：Grad-CAM 热力图
  - 对每个级别的典型样本生成 Grad-CAM
  - 确认模型关注的区域是否与临床判断一致
  - 分析误分类样本的热力图

步骤 3.2：混淆矩阵分析
  - 识别最易混淆的级别对（如 Grade 2 vs Grade 3）
  - 分析混淆原因（数据问题？特征重叠？）

步骤 3.3：特征分析
  - 各级别伤口的视觉特征总结
  - 将模型学到的特征与临床 Wagner/IWGDF 标准对照
```

## 八、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| Grade 2/3 邻级混淆严重 | 模型区分度不够 | 使用 Ordinal Regression（有序回归），利用级别间的序数关系 |
| 图片来自多个数据源，域差异大 | 泛化能力差 | 增加数据增强强度，使用 MixUp/CutMix |
| 原始图片仅 1,373 张 | 可能过拟合 | 强数据增强 + Dropout + Label Smoothing |
| GPU 不可用 | 训练速度慢 | 使用较小模型（EfficientNet-B0）或减少 batch size |
| 模型学到了肤色/背景等虚假特征 | 不公平/不准确 | Grad-CAM 验证 + 测试集多样化评估 |

## 九、后续扩展方向（可选）

1. **多任务学习**：同时预测分级 + 感染 + 缺血
2. **分割 + 分级联合**：先用 U-Net 分割伤口区域，再分级（类似 ScoreDFUNet）
3. **LLM 增强建议**：接入 GPT-4o API，用分级结果 + 患者信息生成更个性化的自然语言建议
4. **移动端部署**：模型导出为 ONNX → TensorFlow Lite，部署到手机 App
5. **纵向追踪**：同一患者多次拍摄，追踪伤口愈合趋势
