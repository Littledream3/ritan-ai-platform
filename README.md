# 日坛 AI 平台

日坛 AI 医疗与经皮智能应用的开源代码仓库。本仓库由生产系统源码快照整理而成，提供前端、后端、数据库迁移、部署模板和示例配置，便于技术评审、学习与二次开发。

## 项目组成

| 目录 | 功能 |
| --- | --- |
| `apps/corporate-platform` | 日坛 AI 官网与综合业务后台 |
| `apps/skin-diagnosis` | AI 测肤服务与移动端检测页面 |
| `apps/skin-landing-source` | 测肤宣传页前端工程 |
| `apps/dfu-platform` | 糖尿病足患者端、医生端、智能分级及报告生成 |
| `apps/dfu-collection` | 医生端患者建档与多媒体采集 |
| `apps/media-drop` | 批量图片、视频上传工具 |
| `apps/ai-transdermal` | AI 精准透皮仿真结果展示页面 |
| `database` | 可移植数据库结构，不含真实业务数据 |
| `env` | 空白环境变量模板 |

## 主要能力

- 糖尿病足影像采集、患者建档、医生工作台和智能分级结果展示。
- AI 测肤的移动端采集、分析流程及营销落地页。
- 批量图片和视频上传、媒体归档及数据库迁移。
- 经皮药物仿真结果与公开人体平均 PK 数据的交互式展示。
- PostgreSQL、MySQL、Redis、Nginx、systemd 与 Docker 部署模板。

## 安全与隐私

公开仓库不包含以下内容：

- 患者姓名、手机号、邮箱、住院号或其他可识别信息；
- 真实数据库、业务日志、上传的临床照片或视频；
- `.env`、SMTP授权码、数据库密码、JWT密钥、API Token或私钥；
- 模型权重、受限训练数据或服务器备份；
- 生产服务器地址和TLS证书。

运行凭据必须通过本地环境变量或密钥管理服务提供。请从 `env/*.env.example` 创建本地配置，任何真实配置均不得提交到Git。

## 本地运行

各应用的依赖和启动方式不同，请先进入对应目录查看说明。通用流程如下：

1. 复制对应的环境变量模板，并仅在本地填写实际配置。
2. 创建独立Python虚拟环境或使用项目Docker配置。
3. 安装目录中的 `requirements.txt` 或 `package.json` 依赖。
4. 初始化空白数据库并执行Alembic迁移。
5. 从授权位置配置模型权重，再启动后端和前端服务。

## 数据与模型声明

仓库中的曲线、测试数据和页面示例仅用于软件功能展示。医疗模型结果、经皮仿真结果及风险提示不构成临床诊断、治疗建议或临床试验结论。模型权重和数据集因体积、授权及隐私要求不在本仓库发布。
